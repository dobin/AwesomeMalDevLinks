## `hklm_exists`

[Permalink: hklm_exists](https://github.com/beune/bof_collection#hklm_exists)

Credit to [Outflank](https://www.youtube.com/watch?v=MxDq552Di3Y) for the research.

[![](https://github.com/beune/bof_collection/raw/master/static/hklm_exists.png)](https://github.com/beune/bof_collection/blob/master/static/hklm_exists.png)

This BOF uses the Remote Registry Protocol (RRP) to enumerate registry keys in HKLM of the target machine. It uses an information leak that discloses the presence of a key when an attempt is made to delete that key.

### IMPORTANT

[Permalink: IMPORTANT](https://github.com/beune/bof_collection#important)

- The BOF will do a sanity check if the key is not accessible by the current user. If it is, the BOF will exit early to prevent regkey deletion.
- Requires user to be domain-joined.
- Remote Registry Service must be running on the target. If the Startup type is not set to "Disabled", it will start automatically in my experience. [The `\\.\pipe\winreg` trick is not needed](https://x.com/splinter_code/status/1715876413474025704) in this case.

## `disk_exists`

[Permalink: disk_exists](https://github.com/beune/bof_collection#disk_exists)

Credit to [Outflank](https://www.youtube.com/watch?v=MxDq552Di3Y) for the research.

[![](https://github.com/beune/bof_collection/raw/master/static/disk_exists.png)](https://github.com/beune/bof_collection/blob/master/static/disk_exists.png)

This BOF uses the Remote Registry Protocol (RRP) to enumerate files/folders of the target machine. It uses an information leak that discloses the presence of a file/folder when an attempt is made save a regkey file to the specified path.

### IMPORTANT

[Permalink: IMPORTANT](https://github.com/beune/bof_collection#important-1)

- The return values presented in the Outflank talk do not match my personal experience. File absence returns `ERROR_ACCESS_DENIED`, file presence returns `ERROR_ALREADY_EXISTS`. Moreover, even though the return value may indicate `ERROR_ACCESS_DENIED`, I have seen that it can still write the file to disk, depending on the current user's privileges. So this BOF may leave artifacts!
- Requires user to be domain-joined.
- Remote Registry Service must be running on the target. If the Startup type is not set to "Disabled", it will start automatically in my experience. [The `\\.\pipe\winreg` trick is not needed](https://x.com/splinter_code/status/1715876413474025704) in this case.

## `patchlevel`

[Permalink: patchlevel](https://github.com/beune/bof_collection#patchlevel)

Credit to [Outflank](https://www.youtube.com/watch?v=MxDq552Di3Y) for the research.

[![](https://github.com/beune/bof_collection/raw/master/static/patchlevel.png)](https://github.com/beune/bof_collection/blob/master/static/patchlevel.png)

This BOF uses the Remote Registry Protocol (RRP) to read `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion`, which contains the exact patch level of a machine.

### IMPORTANT

[Permalink: IMPORTANT](https://github.com/beune/bof_collection#important-2)

- Remote Registry Service must be running on the target. If the Startup type is not set to "Disabled", it will start automatically in my experience. [The `\\.\pipe\winreg` trick is not needed](https://x.com/splinter_code/status/1715876413474025704) in this case.
- Requires user to be domain-joined.

## `remotepipelist`

[Permalink: remotepipelist](https://github.com/beune/bof_collection#remotepipelist)

Credit to [Outflank](https://outflank.nl/blog/2023/10/19/listing-remote-named-pipes/) for the research. This is an improved version over their PoC as it does not require .NET and does authentication over SSPI instead of manually entering credentials.

[![](https://github.com/beune/bof_collection/raw/master/static/remotepipelist.png)](https://github.com/beune/bof_collection/blob/master/static/remotepipelist.png)

This is a self-contained SMB2 client that connects to the remote machine over TCP/445, authenticates the current user using SSPI and enumerates the named pipes from the `IPC$` share.

### IMPORTANT

[Permalink: IMPORTANT](https://github.com/beune/bof_collection#important-3)

- Requires user to be domain-joined.

## `cat`

[Permalink: cat](https://github.com/beune/bof_collection#cat)

Prints contents of a file. Does size checking in order not to overload the CS console, sanitizes output for weird characters and is UTF8 and UTF16 compatible. Also supports UNC paths.

[![](https://github.com/beune/bof_collection/raw/master/static/cat.png)](https://github.com/beune/bof_collection/blob/master/static/cat.png)

## `CVE-2019-16098`

[Permalink: CVE-2019-16098](https://github.com/beune/bof_collection#cve-2019-16098)

Abuses a kASLR leak together with R/W primitive in RTCore64.sys to steal a SYSTEM token. Implemented the remainder as per [Julian Peña's writeup](https://julian-pena.com/2025-09-29-exploiting-drivers-1/). Was a fun little introduction to kernel exploit dev :)

[![](https://github.com/beune/bof_collection/raw/master/static/CVE-2019-16098.png)](https://github.com/beune/bof_collection/blob/master/static/CVE-2019-16098.png)

# Compilation instructions

[Permalink: Compilation instructions](https://github.com/beune/bof_collection#compilation-instructions)

Other than your usual MinGW compiler, this repo requires [boflink](https://github.com/MEhrn00/boflink) in `$PATH`. Other than that, just run `make`!
