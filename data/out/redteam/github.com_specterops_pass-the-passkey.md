# Pass-the-Passkey Family of Attacks

[Permalink: Pass-the-Passkey Family of Attacks](https://github.com/SpecterOps/pass-the-passkey#pass-the-passkey-family-of-attacks)

This repository contains a collection of tools and resources related to the Pass-the-Passkey family of attacks,
which target WebAuthn and FIDO2 authentication mechanisms in Windows
and were featured in the [Black Hat USA 2026 talk](https://blackhat.com/us-26/briefings/schedule/?#pass-the-passkey-family-of-attacks-51821).
These tools are designed for security researchers and penetration testers to assess the security of systems that use passkey-based authentication.

[![Pass-the-Passkey attack diagram](https://github.com/SpecterOps/pass-the-passkey/raw/main/Assets/pass-the-passkey-attack.png)](https://github.com/SpecterOps/pass-the-passkey/blob/main/Assets/pass-the-passkey-attack.png)

Warning

The techniques described in this repository are intended for educational purposes only.
Unauthorized use of these procedures may violate laws and regulations.

### Passkey Injector

[Permalink: Passkey Injector](https://github.com/SpecterOps/pass-the-passkey#passkey-injector)

[![MIT License](https://camo.githubusercontent.com/784362b26e4b3546254f1893e778ba64616e362bd6ac791991d2c9e880a3a64e/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f4c6963656e73652d4d49542d677265656e2e737667)](https://github.com/SpecterOps/pass-the-passkey/blob/main/LICENSE)[![Windows 11](https://camo.githubusercontent.com/734e0bab0abed3123270550896d784a9ea1a78357d7bac74781ac3e60fecbc03/68747470733a2f2f62616467656e2e6e65742f62616467652f69636f6e2f31313f69636f6e3d77696e646f7773266c6162656c3d57696e646f7773)](https://github.com/SpecterOps/pass-the-passkey#)[![.NET 10.0+](https://camo.githubusercontent.com/5c3fac19841b93d3b9eb88ec4d20bd991c925f2e16d1c1bccb25ccddb6ee42b1/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f52756e74696d652d31302e302532422d3030374646462e7376673f6c6f676f3d2e6e6574)](https://github.com/SpecterOps/pass-the-passkey#)[![Visual Studio 2026](https://camo.githubusercontent.com/f3c39fbc044069ca3ee86dc76a17962b4036e59b2e03f935a7c321e8a5b42715/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f56697375616c25323053747564696f2d323032362d3338333237382e737667)](https://github.com/SpecterOps/pass-the-passkey#)[![Visual Studio Code](https://camo.githubusercontent.com/1837720ba5e69532ab0dcdf18d22368a6f3834e357409eb9fd9c7dcc2fb001d6/68747470733a2f2f696d672e736869656c64732e696f2f62616467652f56697375616c25323053747564696f2d436f64652d3030374143432e7376673f6c6f676f3d76697375616c2d73747564696f2d636f6465)](https://github.com/SpecterOps/pass-the-passkey#)[![CI Build](https://github.com/SpecterOps/pass-the-passkey/actions/workflows/autobuild.yml/badge.svg)](https://github.com/SpecterOps/pass-the-passkey#)

The Passkey Injector is a simple web browser built on the Edge WebView2 control
that intercepts WebAuthn assertion requests and allows responses to be injected in JSON format.

[![Screenshot of Passkey Injector](https://github.com/SpecterOps/pass-the-passkey/raw/main/Assets/passkey-injector.png)](https://github.com/SpecterOps/pass-the-passkey/blob/main/Assets/passkey-injector.png)

There are multiple use cases for tampering with the passkey authentication flow, including:

- Replay of captured assertions from network traffic, API hooks, or browser logs.
- Phishing attacks by forwarding attacker-controlled assertions.
- Injection of modified assertions to test server-side validation.
- Signing challenges using stolen synchronized passkeys, e.g., from KeePassXC or Bitwarden.
- Analysis of WebAuthn features and extensions used by a particular cloud service.
- Learning how the WebAuthn protocol works.

[![Passkey Injector architecture diagram](https://github.com/SpecterOps/pass-the-passkey/raw/main/Assets/passkey-injector-architecture.png)](https://github.com/SpecterOps/pass-the-passkey/blob/main/Assets/passkey-injector-architecture.png)

### SharpPasskeys Tool

[Permalink: SharpPasskeys Tool](https://github.com/SpecterOps/pass-the-passkey#sharppasskeys-tool)

This tool is a .NET Framework 4.8 assembly designed to be executed as a payload
by a Windows C2 agent like [Apollo](https://docs.specterops.io/mythic-agents/apollo-docs/documentation-payload/apollo), part of the [Mythic](https://mythic-c2.net/) C2 framework.

The main purpose of this payload is to display a passkey authentication prompt to the user
and retrieve the resulting assertion. It can also list available Windows Hello credentials
and monitor the Windows Event Log for new WebAuthn authentication events.

See the [SharpPasskeys documentation](https://github.com/SpecterOps/pass-the-passkey/blob/main/Documentation/SharpPasskeys.md) for more information.

### WebAuthn Hook

[Permalink: WebAuthn Hook](https://github.com/SpecterOps/pass-the-passkey#webauthn-hook)

The WebAuthn Hook is a native DLL that SharpPasskeys can inject into browser processes.
It uses Microsoft Detours to intercept the [`WebAuthNAuthenticatorGetAssertion`](https://learn.microsoft.com/en-us/windows/win32/api/webauthn/nf-webauthn-webauthnauthenticatorgetassertion) Win32 API call,
allowing operators to observe and tamper with the WebAuthn assertion workflow.

The hook communicates with the SharpPasskeys process over the `\\.\pipe\WebAuthnHook` named pipe.
Through this control channel, SharpPasskeys can monitor assertion requests and responses, capture the
resulting `PublicKeyCredential`, inject a replacement `challenge`, or withhold
a successful assertion from the browser.

See the [WebAuthn Hook documentation](https://github.com/SpecterOps/pass-the-passkey/blob/main/Documentation/WebAuthnHook.md) for more information.

### DSInternals Passkey UI

[Permalink: DSInternals Passkey UI](https://github.com/SpecterOps/pass-the-passkey#dsinternals-passkey-ui)

`Passkey UI` is a simple Windows application that provides a graphical user interface for interacting with the Windows WebAuthn API. The source code of this tool is hosted in the [webauthn-interop](https://github.com/MichaelGrafnetter/webauthn-interop) repository.

[![Passkey UI Screenshot](https://github.com/SpecterOps/pass-the-passkey/raw/main/Assets/passkey-ui.png)](https://github.com/SpecterOps/pass-the-passkey/blob/main/Assets/passkey-ui.png)

### DSInternals.Passkeys PowerShell Module

[Permalink: DSInternals.Passkeys PowerShell Module](https://github.com/SpecterOps/pass-the-passkey#dsinternalspasskeys-powershell-module)

The [DSInternals.Passkeys](https://www.powershellgallery.com/packages/DSInternals.Passkeys) PowerShell module lets Microsoft Entra ID and Okta administrators register passkeys on behalf of other users. The source code of this module is hosted in the [webauthn-interop](https://github.com/MichaelGrafnetter/webauthn-interop) repository.

[![PowerShell Passkey Registration Screenshot](https://github.com/SpecterOps/pass-the-passkey/raw/main/Assets/powershell.png)](https://github.com/SpecterOps/pass-the-passkey/blob/main/Assets/powershell.png)

### Entra ID Synced Passkey Login

[Permalink: Entra ID Synced Passkey Login](https://github.com/SpecterOps/pass-the-passkey#entra-id-synced-passkey-login)

Fabian Bader's [Invoke-EntraIDPasskeyLogin.ps1](https://github.com/f-bader/TokenTacticsV2/blob/main/modules/Invoke-EntraIDPasskeyLogin.ps1), part of the [TokenTacticsV2](https://github.com/f-bader/TokenTacticsV2) toolkit, performs a non-interactive Entra ID sign-in using a WebAuthn private key extracted from a synced vault (Bitwarden, 1Password, KeePassXC) and returns OAuth tokens usable against Microsoft Graph. A modified variant, [Invoke-EntraPasskeyInjection.ps1](https://github.com/SpecterOps/pass-the-passkey/blob/main/Src/Scripts/Invoke-EntraPasskeyInjection.ps1), is included in this repository and accepts a precomputed `PublicKeyCredential` payload so it can be chained with assertions from the **Passkey Injector** and **SharpPasskeys** tools.
