# GDRVLoader - Load Unsigned Drivers Windows 10-11

[Permalink: GDRVLoader - Load Unsigned Drivers Windows 10-11](https://github.com/zer0condition/GDRVLoader#gdrvloader---load-unsigned-drivers-windows-10-11)

Originally based from [https://github.com/fengjixuchui/gdrv-loader](https://github.com/fengjixuchui/gdrv-loader) but with improvements and support for latest windows versions.

## Added Features

[Permalink: Added Features](https://github.com/zer0condition/GDRVLoader#added-features)

- Load unsigned drivers on Windows 10-11 without getting caught by PatchGuard.
- Improved portability through the addition of byte loading for the vulnerable driver
- CRT compatibility, for cleaner code and easier usage.
- Simple and user-friendly command-line interface

## Usage

[Permalink: Usage](https://github.com/zer0condition/GDRVLoader#usage)

1. Download the latest release.
2. a) Drag the target driver into GDRVLoader.exe.

    b) Run the tool from the cmd using administrator privileges with command "GDRVLoader.exe TargetDriver.sys".
3. Enter load/LOAD or unload/UNLOAD in the command prompt.
